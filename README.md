# dsh-desktop-plus

## 功能概览

- **删除会话**：会话行垃圾桶或「…」菜单，二次确认后连同日志与缓存一起删除，归档与置顶不受影响。
- **批量清理**：工作区「…」→「清理会话…」，多选、一次确认，逐条给出「已删除 / 已跳过 / 失败」，失败项可单独重试。
- **撤回与重新编辑**：用户消息可「撤回」「重新编辑」，助手回复可「撤回」。撤回带走这条及其之后的内容，被撤回的提问回到输入框，改完直接替换发送。
- **对话预览**：对话右侧按轮次列出全文，当前轮高亮，点哪跳哪；可拖宽、可收成窄轨，滚上去自动暂停跟随。

## 安装

需要 DSH 0.2.x（本机验证版本 0.2.2-rc.5）。

```sh
dsh plugin --profile desktop add dsh-desktop-plus
```

profile 名按你实际用的改。装完重启 DSH；更新时重新执行同一条命令即可。

<details>
<summary>本地开发：链接安装</summary>

```sh
dsh plugin --profile desktop add link:/absolute/path/to/dsh-desktop-plus
```

改动落在源目录，不用重装；但改了 `lib/*.js` 仍要禁用再启用插件才会生效。

</details>

## 配置

在 profile 的 `cordis.patch.yml` 里按 id 覆盖：

```yaml
- id: dsh-desktop-plus
  config:
    allowLiveSessionDelete: false
```

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| `allowLiveSessionDelete` | `true` | 允许删除 DSH 仍在内存中持有的会话。关闭后这类会话一律拒绝，需要重启应用后才能删。 |

## 使用

| 操作 | 位置 | 说明 |
| --- | --- | --- |
| 删除会话 | 会话行垃圾桶、「…」菜单 | 确认框写明标题与释放的空间；仍在生成回复或跑任务的会话会说明原因并拒绝 |
| 批量清理 | 工作区「…」→「清理会话…」 | 勾选后一次确认，结束后逐条汇总，失败项可重试 |
| 撤回消息 | 每条消息的操作行 | 确认框写明将清掉多少条；被撤回的提问回到输入框 |
| 再次编辑 | 用户消息的操作行 | 原文回到输入框，`Enter` 替换并发送，`Esc` 放弃 |
| 对话预览 | 对话右侧常驻栏 | 拖左边缘调宽、双击复位、列头可收窄；未加载的轮次点一下展开 |

## 注意事项

- **删除不可恢复**，会清掉该会话的日志与投影缓存；归档只是收起来，两者互不影响。
- 删除仍被 DSH 持有的会话后，它可能在重启前以空行重新出现一次。
- 撤回不删日志原文，界面上也没有撤销入口；带图的提问，图片随文本回到输入框，只改文字时需手动重加。
- 预览是只读的，不改动任何记录。
- 这些操作只给界面用，agent 调不到。

## 常见问题

**装上没反应？**
先重启 DSH，确认装进了当前使用的 profile。

**删除和归档有什么区别？**
归档随时可以恢复；删除会真的清掉日志和缓存，无法恢复。

**撤回能撤销吗？**
不能。撤回只是让模型和界面从这条消息之前重新开始，原文仍在本地日志里，但没有恢复入口。
